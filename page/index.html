HK25 catalogue as STAC: search prototype

Generated from the HK25 Intake catalogue as an experiment for HK27. Everything here is static: a flat index.json built by CI from the STAC Items, filtered in the browser. The STAC tree is at stac/catalog.json. Experiment, domain and product type are inferred from HK25 ids and metadata.

Catalogue

Open any dataset the same way at every node: km_scale.open_dataset(id, freq, zoom) (gridded data), open_table (tracks), get_url (anything else); km_scale.where(id) shows which copy each site reads. The site comes from KM_SCALE_USER_LOCATION on each JupyterHub; see sites.yaml.
